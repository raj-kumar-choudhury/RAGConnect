# RAGConnect POC

RAGConnect is a Python FastAPI service that provides an integration layer between SkillFlow applications and RAGFlow.

RAGFlow manages document ingestion, parsing, chunking, embeddings, retrieval, and RAG workflows.

The purpose of this document is to validate the RAGConnect to RAGFlow document ingestion and retrieval pipeline.

RAGConnect communicates with RAGFlow through its HTTP API using an authenticated API key.
